# לוג ריצות תוסף המדיניות

התוסף כותב לכאן בכל ריצה:
- `latest.json` - התקדמות כל ~3 דקות בזמן ריצה, ולוג מלא בסוף (או שגיאת ריצה).
- `runs/<זמן>.json` - עותק של כל ריצה שהסתיימה.

לכל אתר: עמודים, כמה קישורים/קבצים נמצאו, מה נבחר כמדיניות, קבצים שלא נבחרו (עם הטקסט שלידם), כבר-קיימים, חדשים, שגיאות.
