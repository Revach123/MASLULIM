הגדרות - מעקב דוחות רשות שוק ההון

הטוקן נשמר מקומית בדפדפן בלבד ונשלח אך ורק ל-api.github.com.

איך מפיקים טוקן

  1. GitHub → Settings → Developer settings → Fine-grained personal access tokens → Generate new token.
  2. Resource owner: החשבון שלך. Repository access → Only select repositories → בחר את הרפו הזה.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate, העתק את הטוקן (github_pat_...) והדבק כאן.
